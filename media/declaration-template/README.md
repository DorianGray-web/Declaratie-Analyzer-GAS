# Declaration Template Evidence

This directory contains public-safe visual material representing the declaration
template used by Declaratie Analyzer.

The template image documents the structure and presentation of the declaration
form. It may be used in project documentation and architecture review.

It does not contain declarant data and is not a runtime input or source of
financial truth.

The authoritative declaration workflow remains defined by the project
architecture and accepted ADRs. The production output is generated by populating
a copy of the native Google Sheets template and exporting that populated sheet
to PDF.
